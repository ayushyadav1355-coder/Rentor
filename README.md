# Rentor 2.0 🏠✨

An intelligent, AI-powered platform designed to streamline and elevate the rental experience. Built with a modern React architecture, Rentor 2.0 leverages the Gemini API to provide smart recommendations, automated property insights, and a seamless user interface.

## 🚀 Features

* **AI-Powered Insights:** Integrates the Gemini API to deliver intelligent property descriptions and dynamic user assistance.
* **Modern Interface:** Fast, responsive, and type-safe UI built with React and TypeScript.
* **Optimized Performance:** Lightning-fast builds and instant hot module replacement powered by Vite.
* **Secure Configuration:** Environment-based key management for safe API integrations.

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite
* **AI Integration:** Google Gemini API
* **Package Manager:** npm
